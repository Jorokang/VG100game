# Readme
This file contains relevant information about installation and startup.

## Installation
The OS:	[Windows]

[Install Elm]
```
Follow the guide in the website below
https://elm-lang.org/install
```

[Clone this repo and cd into it]
```
In your terminal, input:
cd [the repo directory name]
```

[Run elm reactor] 
```
After cd into the repo, run:
elm reactor
You will see [Go to http://localhost:8000 to see your project dashboard.]
```

[Open the html] 
```
Open the url in the browser, then you can find a lot of files.
Find the "index.html" and click on it.
```

## Usage

[Choose level]
```
enter the level you choose by click it
```

[Play card]
```
Play out the card you choose by click it
```

[Move]
```
In player's turn, click the yellow circle to move it
```
